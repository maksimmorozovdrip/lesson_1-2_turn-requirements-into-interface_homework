# Практические примеры HTML и CSS

В разделе находятся 10 небольших изолированных примеров. Каждый пример показывает один основной приём и содержит мини-задачу для самостоятельного изменения кода.

1. `01-semantic-html` — семантическая структура и заголовки;
2. `02-bem` — именование классов по БЭМ;
3. `03-box-model` — блочная модель и `box-sizing`;
4. `04-flexbox` — одномерная раскладка;
5. `05-grid` — двумерная раскладка;
6. `06-responsive` — базовая адаптивная вёрстка;
7. `07-css-variables` — CSS-переменные и единая тема;
8. `08-interactive-states` — `hover`, `focus-visible` и `active`;
9. `09-form-styling` — доступная разметка и стили формы;
10. `10-combined-layout` — совместное применение БЭМ, Flexbox, Grid и адаптива.

## Как работать с примером

1. Откройте его `index.html` через Live Server.
2. Посмотрите разметку и соответствующий `styles.css` рядом.
3. Измените значения, указанные в мини-задаче.
4. Сразу проверьте результат в браузере.
5. Перенесите приём в свой проект осознанно, а не копируйте пример целиком.

Файл `common.css` отвечает только за оформление учебной страницы. Основной материал каждого примера находится в его локальном `styles.css`.
