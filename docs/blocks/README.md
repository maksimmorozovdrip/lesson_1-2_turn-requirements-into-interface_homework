# Библиотека блоков

В библиотеке собраны 10 типов интерфейсных блоков. Для каждого типа подготовлено по три варианта с разной композицией и стилистикой.

1. `01-headers` — меню и шапки;
2. `02-heroes` — первые экраны;
3. `03-story` — основной рассказ или описание;
4. `04-events` — события и этапы;
5. `05-facts` — факты и показатели;
6. `06-cards` — универсальные карточки;
7. `07-lists` — списки, шаги и тезисы;
8. `08-quotes` — цитаты и акцентные мысли;
9. `09-contact-forms` — формы обратной связи;
10. `10-footers` — подвалы страницы.

## Как использовать

1. Откройте `index.html` нужной категории через Live Server.
2. Выберите один вариант исходя из ТЗ, а не только из личного вкуса.
3. Скопируйте HTML выбранного компонента в свою страницу.
4. Найдите одноимённый раздел в `styles.css` и перенесите нужные правила.
5. Замените демонстрационный текст содержанием из ТЗ.
6. При необходимости измените классы, цвета и композицию под задачу.

Не нужно добавлять на страницу все блоки и все варианты. Заготовки не являются готовым сайтом и намеренно не содержат адаптивной вёрстки или JavaScript.
